# Ошибка при объединении потоков

В этом задании нужно исправить ошибочный результат при удалении нескольких записей
с помощью операторов RxJS.

## Запуск

Команды выполняй из корня репозитория:

```bash
npm install
npm run serve:rxjs-high-order-operator-bug
```

Если зависимости уже установлены, достаточно выполнить вторую команду.

После запуска появится список записей и три кнопки:

- **Удалить food** — удалить записи с темой `food`;
- **Удалить sport** — удалить записи с темой `sport`;
- **Удалить book** — удалить записи с темой `book`.

Фейковая локальная база работает предсказуемо: запись с `id = 6` возвращает
`false`, остальные записи возвращают `true`. Значение `false` означает неуспешное
удаление, но не является уведомлением RxJS `error`.

## Что посмотреть

Открой файлы:

- `src/app/app.component.ts` — компонент с кнопками;
- `src/app/app.service.ts` — объединение потоков удаления;
- `src/app/localDB.service.ts` — фейковая база данных.

Метод `deleteOldTopics(type)`:

1. находит записи выбранной темы;
2. создаёт для каждой записи `Observable<boolean>`;
3. объединяет эти потоки и возвращает результат.

## Воспроизведение ошибки

1. Перезагрузи страницу.
2. Убедись, что у темы `food` есть записи `id = 5` и `id = 6`.
3. Нажми **Удалить food**.

Интерфейс ошибочно покажет сообщение об успехе, хотя удаление записи `id = 6`
вернуло `false`. Запись `id = 6` останется в списке.

## Причина

Открой `src/app/app.service.ts`:

```ts
return infoByType.length > 0
  ? infoByType
      .map((t) => this.dbService.deleteOneTopic(t.id))
      .reduce((acc, curr) => merge(acc, curr), of(true))
  : of(true);
```

`merge` передаёт значения всех входных потоков по мере их появления. Начальный
поток `of(true)` сразу выдаёт `true`, а компонент получает только первое значение
из-за `take(1)`. Поэтому результаты отдельных удалений не учитываются.

## Задание

Измени только логику в `app.service.ts`, чтобы итоговый поток выдавал:

- `true`, если все удаления успешны;
- `false`, если хотя бы одно удаление вернуло `false`.

Можно использовать `reduce`, `scan`, `forkJoin` или другой подход, который
сначала получает все результаты, а затем сворачивает их в одно значение.

Публичный интерфейс компонентов менять нельзя.

## Проверка решения

1. **Удалить food** — должно появиться сообщение об ошибке.
2. **Удалить sport** — должно появиться сообщение об успехе.
3. **Удалить book** — должно появиться сообщение об успехе.
4. Перезагрузи страницу и повтори проверку: результат должен оставаться тем же.
