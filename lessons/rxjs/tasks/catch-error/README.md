# Обработка ошибок: `catchError`

В этом задании нужно обработать ошибку внутреннего потока так, чтобы внешний поток
событий продолжил принимать новые значения.

## Запуск

Команды выполняй из корня репозитория:

```bash
npm install
npm run serve:rxjs-catch-error
```

Если зависимости уже установлены, достаточно выполнить вторую команду.

После запуска откроется форма с полем ввода и кнопкой **Получить**. Приложение
обращается к API `https://jsonplaceholder.typicode.com/`.

## Что проверить

Введи одно из значений:

- `posts`
- `comments`
- `albums`
- `photos`
- `todos`
- `users`

Нажми **Получить** и посмотри ответ. Затем введи `foo` и снова отправь форму.
Запрос завершится ошибкой `404`, это ожидаемо.

После этого введи `posts` и отправь форму ещё раз.

Из-за ошибки внешний поток `submit$` завершился, поэтому новый запрос не выполняется.

## Где искать причину

Открой `src/app/app.component.ts`:

```ts
this.submit$
  .pipe(
    map(() => this.input),
    concatMap((value) =>
      this.http.get(`https://jsonplaceholder.typicode.com/${value}/1`),
    ),
    takeUntilDestroyed(this.destroyRef),
  )
  .subscribe({...});
```

Ошибка внутреннего `Observable` передаётся наружу и завершает подписку на `submit$`.
После этого новые нажатия никто не обрабатывает.

Подробнее: [документация `catchError`](https://rxjs.dev/api/operators/catchError).

## Задание

1. Открой `src/app/app.component.ts`.
2. Найди место, где внутри `concatMap` создаётся HTTP-запрос.
3. Добавь `catchError` внутрь функции `concatMap`.
4. В обработчике запиши ошибку в консоль и верни резервный поток.
   Чтобы ошибка осталась видимой в текущем интерфейсе, можно вернуть `of(error)`.
5. Не создавай новую подписку на `submit$`.

Важно: `catchError` должен находиться внутри `concatMap`, а не после него.

## Проверка решения

1. `posts` — отображается ответ.
2. `foo` — отображается ошибка или предусмотренное резервное состояние.
3. `comments` — снова отображается ответ.
4. Повтори шаги 2–3 несколько раз. Поток должен продолжать работать.

Каждое нажатие должно оставаться видимым в консоли.
