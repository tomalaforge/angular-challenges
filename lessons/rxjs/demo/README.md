# Интерактивная практика RxJS

Демонстрационное приложение к [лекции по RxJS](../lecture/RxJS%20%E2%80%94%20%D0%9B%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%20%28Markdown%29.md).

В приложении 8 сценариев. Каждый показывает одну задачу в двух вариантах:
обычном и с операторами RxJS. Журнал событий помогает увидеть порядок значений,
ошибки, отмену и очистку подписок.

## Запуск

```bash
cd lessons/rxjs/demo
npm install
npm start
```

Приложение откроется по адресу `http://localhost:4200`.

## Сценарии и разделы лекции

| Сценарий | Операторы | Раздел лекции |
|---|---|---|
| Живой поиск | `debounceTime`, `distinctUntilChanged`, `switchMap` | 8.1, 5 |
| Быстрая навигация | `switchMap` | 8.2, 5 |
| Отправка формы | `exhaustMap` | 8.3, 5 |
| Параллельные запросы | `mergeMap`, `forkJoin` | 5, 6 |
| Загрузка и ошибки | `startWith`, `catchError`, `retry` | 8.5, 4, 6 |
| Фильтры и адресная строка | `combineLatest`, `switchMap`, `startWith` | 8.4, 6 |
| Утечки подписок | `takeUntilDestroyed` | 2, 7 |
| Кэширование настроек | `shareReplay` | 6 |

## Как работать

1. Выбери сценарий.
2. Повтори действие в обеих колонках.
3. Сравни результат и записи в журнале событий.
4. Сверь наблюдение с соответствующим разделом лекции.
